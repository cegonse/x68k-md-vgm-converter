# YM2612 — Target FM Chip (Mega Drive)

Register reference for the **output** FM chip. The transcriber emits YM2612
register writes (VGM commands `0x52` port 0 / `0x53` port 1). This documents
the register map and bit layouts the writer must produce. Derived from the
BlastEm emulator (`ym2612.c` / `ym2612.h`, Michael Pavone, GPL-3) — chosen
over the scanned Yamaha datasheet for precision and parseability.

For the actual YM2151→YM2612 mapping, see `../conversion-mapping.md`. This
file is the target-side reference only.

## Overview

- **6 FM channels**, **4 operators each** (24 operators total).
- Two register banks selected by port: **port 0** covers channels 1–3,
  **port 1** covers channels 4–6. Global/shared registers live in port 0
  only.
- Channel 6 doubles as the **DAC/PCM channel** when DAC is enabled (see
  `REG_DAC` / `REG_DAC_ENABLE`). This is the channel the XGM driver / PCM
  mixing takes over — hence the "reserve ch6 for PCM" rule.
- VGM writes: `0x52 aa dd` = port 0 reg `aa` = `dd`; `0x53 aa dd` = port 1.

## Register regions

Registers below `0x30` are **global/shared** (port 0 only). Registers
`0x30`–`0x9F` are **per-operator**. Registers `0xA0`–`0xB7` are
**per-channel**. Valid register range is `0x21`–`0xB7`.

| Reg | Name | Scope |
|-----|------|-------|
| `0x22` | LFO enable + frequency | Global |
| `0x24` | Timer A high | Global |
| `0x25` | Timer A low | Global |
| `0x26` | Timer B | Global |
| `0x27` | Timer control / Ch3 mode | Global |
| `0x28` | Key on/off | Global |
| `0x2A` | DAC data | Global |
| `0x2B` | DAC enable | Global |
| `0x30`–`0x3F` | Detune / Multiple | Per-operator |
| `0x40`–`0x4F` | Total Level | Per-operator |
| `0x50`–`0x5F` | Attack Rate / Key Scaling | Per-operator |
| `0x60`–`0x6F` | Decay Rate / AM enable | Per-operator |
| `0x70`–`0x7F` | Sustain Rate | Per-operator |
| `0x80`–`0x8F` | Release Rate / Sustain Level | Per-operator |
| `0x90`–`0x9F` | SSG-EG | Per-operator |
| `0xA0`–`0xA3` | F-number low | Per-channel |
| `0xA4`–`0xA7` | Block + F-number high | Per-channel |
| `0xA8`–`0xAF` | Ch3 supplementary F-num (special mode) | Ch3 only |
| `0xB0`–`0xB3` | Algorithm / Feedback | Per-channel |
| `0xB4`–`0xB7` | L/R / AMS / PMS | Per-channel |

## Global register bit layouts

### `0x22` — LFO
```
bit 3    LFO enable (1 = on)
bit 0-2  LFO frequency (0-7)
```
When disabled, AM/PM stepping stops.

### `0x24` / `0x25` — Timer A (10-bit)
```
0x24: bits 9-2 of Timer A load (value << 2)
0x25: bits 1-0 of Timer A load (value & 0x3)
```

### `0x26` — Timer B (8-bit)
```
whole byte = Timer B load
```

### `0x27` — Timer control + Channel 3 mode
```
bit 7-6  Channel 3 mode (0x00 = normal, 0x40 = special/multi-frequency,
                         other = CSM per hardware)
bit 5    Timer B reset (clears status flag)
bit 4    Timer A reset
bit 3    Timer B enable
bit 2    Timer A enable
bit 1    Timer B load/start
bit 0    Timer A load/start
```

### `0x28` — Key on/off
```
bit 7    operator 4 key
bit 6    operator 3 key
bit 5    operator 2 key
bit 4    operator 1 key
bit 2-0  channel select
```
Channel select encoding (this is a **quirk** — not a plain 0–5):
```
0 → ch1   1 → ch2   2 → ch3
4 → ch4   5 → ch5   6 → ch6
3 and 7 → invalid (ignored)
```
i.e. bit 2 selects the port/bank (ch4–6), bits 1–0 the channel within it,
and value 3/7 must never be emitted. The operator key bits `0xF0` say which
of the channel's 4 operators are keyed on.

### `0x2A` — DAC data
```
8-bit unsigned PCM sample; when DAC enabled, drives channel 6 output.
Hardware maps it as ((value) - 0x80) << 6 internally (i.e. 0x80 = silence).
```
In VGM this is often fed via the streaming/data-bank mechanism (command
`0x8n`, DAC stream control) rather than one `0x52 2A dd` per sample.

### `0x2B` — DAC enable
```
bit 7    DAC enable (1 = channel 6 replaced by DAC output)
```
When set, channel 6's normal FM output is replaced by the DAC. This is the
switch that makes ch6 the PCM channel.

## Per-operator registers (`0x30`–`0x9F`)

### Operator addressing
Operators are addressed by the low nibble of the register. For a register
in `0x30`–`0x9F`, given the port (0 = ch1–3, 1 = ch4–6):
```
if (reg & 0x3) == 0x3   → invalid (no channel), ignore
channel_in_part = reg & 0x3            (0,1,2)
operator_in_ch  = (reg & 0xC) / 4      (0,1,2,3)
```
So within a bank, the four operators of a channel are at low-nibble offsets
`0x0, 0x4, 0x8, 0xC` plus the channel index `0..2`. Port 1 adds 3 to the
channel number. The `0x?3`, `0x?7`, `0x?B`, `0x?F` slots are unused.

### `0x30`–`0x3F` — Detune / Multiple
```
bit 6-4  Detune (0-7)
bit 3-0  Multiple (0-15)
```

### `0x40`–`0x4F` — Total Level
```
bit 6-0  Total Level (0-127); 0 = loudest, 127 = quietest.
```

### `0x50`–`0x5F` — Attack Rate / Key Scaling (Rate Scaling)
```
bit 7-6  Key Scaling / Rate Scaling (stored as 3 - (value>>6) internally)
bit 4-0  Attack Rate (0-31)
```

### `0x60`–`0x6F` — Decay Rate / AM enable
```
bit 7    Amplitude Modulation enable
bit 4-0  Decay Rate (first decay) (0-31)
```

### `0x70`–`0x7F` — Sustain Rate
```
bit 4-0  Sustain Rate (second decay) (0-31)
```

### `0x80`–`0x8F` — Release Rate / Sustain Level
```
bit 7-4  Sustain Level (0-15); 0xF maps to max envelope internally
bit 3-0  Release Rate (0-15); hardware uses (value<<1 | 1) as effective rate
```

### `0x90`–`0x9F` — SSG-EG
```
bit 3    SSG-EG enable (if clear, whole register treated as 0)
bit 2    Attack
bit 1    Alternate
bit 0    Hold
(bit 3 also acts as the "invert" toggle in combination with the others)
```
SSG-EG has **no YM2151 equivalent**; relevant only when writing YM2612.

## Per-channel registers (`0xA0`–`0xB7`)

Channel addressing: `channel = reg & 0x3` (must not be 3); port 1 adds 3.

### `0xA0`–`0xA3` + `0xA4`–`0xA7` — Frequency (F-number + Block)
Two-step latched write. Write the **high** register first (it latches),
then the **low** register (which commits both):
```
0xA4-0xA7 (high, latched):
    bit 5-3  Block (octave, 0-7)
    bit 2-0  F-number bits 10-8
0xA0-0xA3 (low, commits):
    bit 7-0  F-number bits 7-0
```
Effective: `fnum = (latch & 0x7) << 8 | low_byte`, `block = latch >> 3 & 0x7`.
**Write order matters** — high/latch before low/commit.

### `0xA8`–`0xAF` — Channel 3 supplementary frequency
Only meaningful when channel 3 is in special mode (`0x27` bit 6). Lets the
three operators of ch3 run at independent frequencies. Same latch/commit
split as above. Ignore unless emitting ch3 special mode.

### `0xB0`–`0xB3` — Algorithm / Feedback
```
bit 5-3  Feedback (0-7)
bit 2-0  Algorithm (0-7)
```
The algorithm selects the operator connection topology (which operators
modulate which). The 8 algorithms are standard 4-operator FM routings;
BlastEm's `REG_ALG_FEEDBACK` case enumerates the exact mod-source wiring
per algorithm if needed. **YM2151 uses the same 8 algorithms and the same
feedback encoding**, which makes this field a near-direct copy.

### `0xB4`–`0xB7` — L/R / AMS / PMS (stereo + modulation sensitivity)
```
bit 7    Left output enable
bit 6    Right output enable
bit 5-4  AMS (amplitude modulation sensitivity, 0-3)
bit 2-0  PMS (phase/pitch modulation sensitivity, 0-7)
```
On reset/first write, ensure L/R are enabled or the channel is silent.

## Notes for the writer

- Respect the **two-write latch** for frequency (high before low).
- Never emit channel select `3` or `7` in `0x28`.
- Route channels 1–3 to port 0 (`0x52`), channels 4–6 to port 1 (`0x53`).
- To use PCM: set `0x2B` bit 7 (DAC enable); channel 6 FM is then replaced.
- Algorithm (`0xB0`) and feedback map almost directly from YM2151; envelope
  and TL/rates map closely; SSG-EG and DAC are YM2612-only concerns.
- Full per-algorithm operator wiring is in BlastEm's source if the
  conversion ever needs to reason about modulation routing rather than just
  copying the algorithm number.
