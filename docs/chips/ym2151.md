# YM2151 — Source FM Chip (X68000)

Register reference for the **input** FM chip. The transcriber reads YM2151
register writes from the source VGM (command `0x54 aa dd`) and maps them
onto YM2612 writes. This documents the register map and bit layouts the
parser must interpret. Derived from the MAME YM2151 driver
(`src/mame/ym2151.c`, via maxim-zhao/in_vgm) — source over datasheet for
precision.

For the YM2151→YM2612 mapping, see `../conversion-mapping.md`. This file is
the source-side reference only.

## Overview

- **8 FM channels**, **4 operators each** (32 operators total).
- Single write port (VGM `0x54 aa dd`: register `aa` = value `dd`).
- **X68000 YM2151 clock is 4 MHz** — read the actual value from the VGM
  header (`0x30`); it drives pitch interpretation.
- Register address is 8-bit; the decode groups by high bits (`r & 0xE0`).

## Operator / channel addressing

The low 5 bits of the register select the operator: `op = r & 0x1F`.
Operators are laid out **interleaved by slot across channels**:
```
operator index = channel + 8 * slot
    channel = op & 7        (0-7)
    slot    = (op >> 3) & 3 (0-3)   // the 4 operators of a channel
```
So a channel's four operators are at register-offsets `ch`, `ch+8`,
`ch+16`, `ch+24`. This is different from the YM2612's `0x0/0x4/0x8/0xC`
nibble layout — the transcriber must translate addressing, not just copy
register numbers.

For the global registers (`r & 0xE0 == 0x00`), `r` is matched directly.
For channel-level writes in the `0x20` group, `channel = r & 7`.

## Global registers (`0x00`–`0x1F`)

Matched by exact register number.

### `0x01` — Test / LFO reset
```
bit 1    LFO phase reset
(other bits: test register — ignore for conversion)
```

### `0x08` — Key on/off
```
bit 6    operator C2 (slot 3) key
bit 5    operator M2 (slot 2) key
bit 4    operator C1 (slot 1) key
bit 3    operator M1 (slot 0) key
bit 2-0  channel (0-7)
```
Note the slot/operator bit order and that the **channel is a plain 0–7**
here — unlike the YM2612's `0x28` which uses a bank-encoded channel select.
The operator-enable bits also sit in a different position than YM2612's
`0xF0`. The transcriber must remap both.

### `0x0F` — Noise enable / period
```
bit 7    noise enable
bit 4-0  noise frequency/period
```
The YM2151 noise generator feeds operator C2 of channel 7 only. **No
YM2612 equivalent** — YM2612 has no noise. This is a lossy point (noise is
dropped or must be approximated; see conversion mapping).

### `0x10` / `0x11` — Timer A (10-bit)
```
0x10: Timer A high — bits 9-2 (index = (old & 0x3) | (v << 2))
0x11: Timer A low  — bits 1-0 (index = (old & 0x3FC) | (v & 3))
```

### `0x12` — Timer B (8-bit)
```
whole byte = Timer B value
```

### `0x14` — Control (CSM / IRQ / timer start-stop)
```
bit 7    CSM mode
bit 5    reset Timer B IRQ flag
bit 4    reset Timer A IRQ flag
bit 3    Timer B IRQ enable
bit 2    Timer A IRQ enable
bit 1    load/start Timer B
bit 0    load/start Timer A
```
Timers/IRQ/CSM generally don't carry musical content that maps to YM2612;
usually not translated (see mapping doc).

### `0x18` — LFO frequency
```
bit 7-4  affects LFO overflow (rate coarse)
bit 3-0  LFO counter add (rate fine)
```

### `0x19` — PMD / AMD (modulation depth)
```
bit 7 = 1 → PMD (phase mod depth) = bits 6-0
bit 7 = 0 → AMD (amplitude mod depth) = bits 6-0
```

### `0x1B` — CT2/CT1 output + LFO waveform
```
bit 7-6  CT2/CT1 external output pins (X68000 uses these for external
         control, e.g. ADPCM-related lines — NOT audio; ignore for FM
         conversion)
bit 1-0  LFO waveform (0=saw,1=square,2=triangle,3=noise)
```

## Channel/operator registers (`0x20`–`0x3F` group, `r & 0xE0 == 0x20`)

Sub-selected by `r & 0x18`; channel = `r & 7`.

### `0x20`–`0x27` — RL / Feedback / Connection (algorithm)
```
bit 7    Right enable
bit 6    Left enable
bit 5-3  Feedback (0-7)
bit 2-0  Connection / algorithm (0-7)
```
**Algorithm (0–7) and feedback (0–7) match the YM2612 encoding directly** —
this is the near-copy field. L/R map to YM2612's `0xB4` L/R bits (note bit
positions differ: YM2151 R=bit7/L=bit6; YM2612 L=bit7/R=bit6).

### `0x28`–`0x2F` — Key Code (KC): octave + note
```
bit 6-4  octave (0-7)
bit 3-0  note (0-15; only 12 used per octave with gaps)
```
7-bit value (`v & 0x7F`). Together with Key Fraction this sets pitch. YM2151
pitch is expressed as KC/KF (note-based); **YM2612 uses F-number + Block**.
This is a non-trivial conversion — a note/fraction → fnum/block mapping,
using the source and target clocks. The mapping doc owns this; it is the
single most important pitch computation in the project.

### `0x30`–`0x37` — Key Fraction (KF)
```
bit 7-2  key fraction (6-bit fine pitch); value used as (v >> 2)
```
Fine detune within a semitone. Feeds the same fnum/block computation.

### `0x38`–`0x3F` — PMS / AMS (modulation sensitivity)
```
bit 6-4  PMS (0-7)
bit 1-0  AMS (0-3)
```
Maps to YM2612 `0xB4` PMS/AMS fields.

## Operator parameter registers (grouped by `r & 0xE0`)

Operator selected by `op = r & 0x1F` (see addressing). Each group covers
all 32 operators.

### `0x40`–`0x5F` — DT1 / MUL (detune 1, multiple)
```
bit 6-4  DT1 (detune 1, 0-7)
bit 3-0  MUL (multiple, 0-15; 0 means x0.5)
```
Maps directly to YM2612 `0x30` (Detune/Multiple), same fields.

### `0x60`–`0x7F` — TL (total level)
```
bit 6-0  Total Level (0-127; 0 loudest)
```
Maps directly to YM2612 `0x40`.

### `0x80`–`0x9F` — KS / AR (key scale, attack rate)
```
bit 7-6  Key Scale (0-3)
bit 4-0  Attack Rate (0-31)
```
Maps to YM2612 `0x50` (note YM2612 stores KS as `3-(v>>6)` internally, but
the register bit layout is the same).

### `0xA0`–`0xBF` — AM-enable / D1R (first decay rate)
```
bit 7    LFO AM enable
bit 4-0  D1R / first decay rate (0-31)
```
Maps to YM2612 `0x60` (AM enable + Decay Rate).

### `0xC0`–`0xDF` — DT2 / D2R (detune 2, second decay rate)
```
bit 7-6  DT2 (detune 2, 0-3)
bit 4-0  D2R / second decay / sustain rate (0-31)
```
**DT2 has NO YM2612 equivalent** (YM2612 lacks detune-2). D2R maps to
YM2612 `0x70` (Sustain Rate). DT2 is a lossy drop.

### `0xE0`–`0xFF` — D1L / RR (sustain level, release rate)
```
bit 7-4  D1L / sustain level (0-15)
bit 3-0  RR / release rate (0-15)
```
Maps to YM2612 `0x80` (Sustain Level + Release Rate).

## Summary: mapping character (details in conversion-mapping.md)

| YM2151 field | YM2612 target | Character |
|--------------|---------------|-----------|
| Algorithm, Feedback (`0x20`) | `0xB0` | near-direct copy |
| L/R (`0x20`) | `0xB4` | copy, bit positions swap |
| PMS/AMS (`0x38`) | `0xB4` | direct |
| KC + KF (`0x28`/`0x30`) | fnum + block (`0xA0`/`0xA4`) | **computed** (note→fnum) |
| DT1/MUL (`0x40`) | `0x30` | direct |
| TL (`0x60`) | `0x40` | direct |
| KS/AR (`0x80`) | `0x50` | direct |
| AM/D1R (`0xA0`) | `0x60` | direct |
| DT2/D2R (`0xC0`) | `0x70` | D2R direct; **DT2 dropped** |
| D1L/RR (`0xE0`) | `0x80` | direct |
| Noise (`0x0F`) | — | **dropped** (no YM2612 noise) |
| Timers/CSM/IRQ | — | not translated |
| SSG-EG | (YM2612 `0x90`) | source has none; leave default |

The two hard parts are **pitch** (KC/KF → fnum/block, clock-dependent) and
the **lossy drops** (noise, DT2). Everything else is field-level copying
with addressing translation (YM2151 `ch + 8*slot` → YM2612 bank + nibble).
