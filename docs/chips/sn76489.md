# SN76489 — PSG (Mega Drive) — UNUSED

**This chip is not used by the converter.** It is documented as a stub for
completeness and to record *why* it's out of scope.

## Why it's unused

The Mega Drive pairs the YM2612 with an SN76489 PSG (3 square-wave tone
channels + 1 noise channel, integrated into the Sega VDP). The X68000
source hardware — YM2151 + OKIM6258 — has **no PSG-equivalent chip**. There
is therefore no source data to map onto the SN76489.

Consequences:
- The transcriber emits **no** SN76489 writes.
- The output Mega Drive VGM leaves the SN76489 clock at 0 (chip absent) and
  produces no PSG (`0x50`) commands.
- Downstream, `xgmtool` will simply have no PSG channel data to work with;
  XGM's PSG command (`$1X`) is never generated by this pipeline.

## If PSG support is ever added

Any future PSG use would be a *creative* remap (e.g. moving some YM2151
material onto PSG channels to free FM channels), not a faithful conversion,
and would need its own design. Should that happen, the SN76489 register
model is available in the BlastEm `psg.c` reference:

- Single write port; a leading `0x80` bit selects "latch/data" vs "data".
- Latch byte: `bit 7 = 1`, `bits 6-5 = channel (0-3)`, `bit 4 = type`
  (1 = volume, 0 = tone/noise), `bits 3-0 = low data / volume`.
- Tone channels use a 10-bit frequency counter split across a latch byte
  (low 4 bits) and a following data byte (high 6 bits).
- Noise channel (channel 3) has a 3-bit control: shift-rate (bits 0-1) and
  white/periodic type (bit 2), with an LFSR for noise generation.
- 4-bit per-channel volume (0 = loudest, 0xF = silent), 16-entry volume
  table.

This is reference-only; nothing in the current converter reads or writes
it.
